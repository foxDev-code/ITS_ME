MetroMaarg

A metro travel prototype bringing route planning, ticket journeys and operational dashboards into one experience.

Hackathon project
View source on GitHub ↗

01 / The question

What needed to be clearer?

A journey crosses several decisions: which route to take, what the fare means and where the ticket lives. Those steps need a consistent interface.

02 / The build

From idea to experience.

The repository combines React and TypeScript views with Supabase-backed services. Passenger flows cover routes and tickets, while administrator pages explore train status, analytics and QR generation.

Inside the project

  • Station selection, route options and fare presentation
  • Ticket-booking and QR-code flows
  • Passenger account and ticket history views
  • Administrative train, analytics and QR interfaces

Tools & disciplines

ReactTypeScriptSupabasePostgreSQLTailwind CSSVite

03 / Current scope

Where it stands.

This is an independent prototype, not an official metro service. Public source contains the application flows and backend functions; production transit integration is not claimed.

04 / A design principle

The idea I’m carrying forward.

Designing both passenger and operator views makes the relationship between a simple screen and its underlying data much clearer.
